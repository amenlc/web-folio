# Landing Page para Cafe y Pilates

Actúa como un experto en diseño web especialmente para estudios de Pilates Reformer.

El logotipo está adjunto para que lo coloques encima de la imagen principal.

Realizar una Landing Page solo en HTML5 y CSS3 con imágenes generadas por Nano Banana.

## Instruciones

Las preferencias de estilos y visuales deben seguir las siguientes pautas:

* El color corporativo principal es el hex 8b7869. Puedes jugar con degradados de ese mismo color  
* Usar Bootstrap 5.3  
* Prohibido usar Tailwind CSS  
* Usa buenas prácticas de navegación css y si es necesario usa flexbox y css grid layout.  
* Ocupar Font Awesome para los íconos

Las características principales de la landing page son:

* Diseño responsive  
* El tipo de landing page es de una página que se navega verticalmente.  
* Mismo color y sus transparencias  
* Feedback visual (hovers, focus. estados, etc)  
* Al hacer click en cada sección, debe hacer un scroll suave hasta llegar a la sección destino.
